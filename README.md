# 원식이형 조지기 피해라 — 비공식 Android 포팅

이 저장소는 유튜버 **보따**가 제작한 게임 **「원식이형 조지기 피해라」**를
Android 기기에서도 실행할 수 있도록 포팅한 APK를 제공합니다.

이 프로젝트는 원작자 또는 원작자와 관련된 공식 프로젝트가 아니며, 팬이 개인적으로
제작한 **비공식·비상업적 Android 포팅판**입니다. 게임의 내용은 변경하지 않았으며
Android 환경에서 실행할 수 있도록 패키징만 진행했습니다.

## 다운로드 및 설치

Releases에서 APK 파일을 내려받아 Android 기기에 설치할 수 있습니다.
Google Play에서 배포되는 앱이 아니므로, 설치 과정에서 기기의
`출처를 알 수 없는 앱 설치` 허용이 필요할 수 있습니다.

- 지원 버전: Android 7.0 이상
- 권장 화면 방향: 가로

## 저작권 안내

게임과 게임에 포함된 이미지, 영상, 음원, 캐릭터, 명칭 및 기타 원본 콘텐츠에 대한
저작권과 권리는 원작자인 **유튜버 보따**에게 있습니다. 별도의 제3자 저작물이 포함된
경우 해당 저작물의 권리는 각 권리자에게 있습니다.

이 저장소의 APK는 원작에 대한 소유권을 주장하거나 상업적 이익을 얻기 위한 목적으로
제공되지 않습니다. 이 저장소의 안내 문구가 원작자에게 배포 허락을 받은 것을 의미하지는
않습니다.

원작자 또는 권리자가 배포 중단이나 삭제를 요청할 경우 해당 요청을 확인한 뒤 APK 및
관련 파일을 삭제하겠습니다.
